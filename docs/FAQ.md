# 常见问题（FAQ）

`wyt-sandbox` 仓库的常见问题与简要回答。

## 1. 这个仓库是做什么的？

`wyt-sandbox` 是一个测试用的沙盒仓库，只包含少量示例文本和文档，不承载业务代码，可以随意试用、修改或删除。

## 2. 怎么安装？

不需要安装。仓库里没有运行时代码、依赖清单或构建配置，克隆下来用任意文本编辑器打开即可查看：

```bash
git clone https://github.com/shabe222/wyt-sandbox.git
cd wyt-sandbox
```

## 3. 如何参与贡献或反馈问题？

- 修改内容：直接编辑或删除仓库中的文件即可；如需把改动提交回本仓库，建议新建分支（如 `feat/xxx`），再以 Pull Request 说明改动目的。
- 反馈问题：提交 Issue，尽量附上问题现象、复现步骤、运行环境（操作系统、版本号）和相关日志。

> 本 FAQ 会随仓库变化持续更新，欢迎补充常见问题。
